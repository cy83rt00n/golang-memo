# Go: практические уроки

Учебный проект на Go, покрывающий базовые конструкции языка. Каждый пакет в
`topics/` — отдельная тема с демонстрационным кодом, который запускается из
единой точки входа `main.go`.

## Темы

| Пакет | Что демонстрируется |
|---|---|
| [`basics`](topics/basics) | Массивы; функции: рекурсия, вариативные параметры, именованные результаты, функции как параметры, замыкания |
| [`aliases`](topics/aliases) | Именованные типы и функциональные типы на примере логгера |
| [`structs`](topics/structs) | Структуры и работа с ними |
| [`methods`](topics/methods) | Методы со значением-приёмником и указателем-приёмником |
| [`slices`](topics/slices) | Срезы, копирование, сортировка, сравнение через `reflect.DeepEqual` |
| [`maps`](topics/maps) | Карты (`map`) |
| [`interfaces`](topics/interfaces) | Интерфейсы и проверка типов через `type switch` |
| [`parallel`](topics/parallel) | Горутины, каналы, `sync.WaitGroup` |
| [`pointers`](topics/pointers) | Указатели, передача данных по значению и по ссылке |

## Требования

- Go 1.26+

## Запуск

```bash
go run .
```

или собрать бинарник и запустить его:

```bash
go build -o lessons .
./lessons
```

Программа последовательно вызывает `Test()` каждого пакета и печатает
результаты по каждой теме.

## Структура проекта

```
lessons/
├── go.mod                  # модуль lessons
├── main.go                 # точка входа: вызывает Test() всех тем
└── topics/
    ├── aliases/            # именованные и функциональные типы
    ├── basics/             # базовый синтаксис и функции
    ├── interfaces/         # интерфейсы и type switch
    ├── maps/               # карты
    ├── methods/            # методы (value/pointer receiver)
    ├── parallel/           # конкурентность (горутины, каналы)
    ├── pointers/           # указатели
    ├── slices/             # слайсы
    └── structs/            # структуры
```

## Пример вывода

Каждый пакет печатает заголовок вида `-== Тема ==-` и демонстрационные
строки. Пакеты логирования выводят записи в формате «время, уровень, код,
текст», например:

```
[2026-11-20T14:00:00+03:00][debug] (100) Log messages test
```
